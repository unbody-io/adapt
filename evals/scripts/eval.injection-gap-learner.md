# injection-gap-learner

**Purpose:** Focused eval for the injection gap learner — dismissed data to new learner flow.

**Evaluates:**
- Narrow Brain dismissing most incoming data
- Gap learner detecting dismissed domains
- Evaluator creating new learners for uncovered domains
- Re-injection of dismissed batches

**Parameters:**
- Model: configurable via `MODEL` env var
- Dataset: digital-twin-daily.json
