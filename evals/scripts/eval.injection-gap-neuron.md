# injection-gap-neuron

**Purpose:** Focused eval for the injection gap neuron — dismissed data to new neuron flow.

**Evaluates:**
- Narrow Brain dismissing most incoming data
- Gap neuron detecting dismissed domains
- Evaluator creating new neurons for uncovered domains
- Re-injection of dismissed batches

**Parameters:**
- Model: configurable via `MODEL` env var
- Dataset: digital-twin-daily.json
